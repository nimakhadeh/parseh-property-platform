# 🏠 پلتفرم املاک پارسه (Parseh Property Platform)

پلتفرمی حرفه‌ای برای مدیریت، نمایش و تحلیل هوشمند املاک — ساخته شده با Django، Tailwind CSS، HTMX و اتصال به هوش مصنوعی DeepSeek.

---

## 📋 معرفی پروژه

پلتفرم املاک پارسه امکاناتی مانند موارد زیر را فراهم می‌کند:

- نمایش و **جستجوی پیشرفته** املاک (نوع معامله، قیمت، متراژ، تعداد اتاق، امکانات) با اسکرول بی‌نهایت
- **نقشه تعاملی** (Leaflet + OpenStreetMap) روی لیست و جزئیات ملک
- **علاقه‌مندی‌ها (Wishlist)** و **مقایسه تا ۳ ملک** کنار هم — بدون نیاز به ثبت‌نام
- صفحه جزئیات ملک با گالری تصاویر و فرم درخواست بازدید
- **تحلیل هوشمند ملک** با اتصال به DeepSeek API (مزایا، معایب، بازه قیمت پیشنهادی و امتیاز کلی)
- معرفی تیم مشاوران و صفحه **پرسش‌های متداول (FAQ)**
- وبلاگ با مقالات قابل اشتراک‌گذاری
- فرم تماس با پردازش HTMX (بدون رفرش صفحه) + **اعلان تلگرام** آنی برای مدیر سایت
- **سئوی کامل** — sitemap.xml، robots.txt، Open Graph tags برای اشتراک‌گذاری بهتر در شبکه‌های اجتماعی
- طراحی کاملاً فارسی و راست‌چین (RTL) با پشتیبانی کامل موبایل

## 🧱 پشته فناوری (Tech Stack)

## 🚀 نصب سریع روی سرور (کمتر از ۱۰ دقیقه)

۱. پروژه را روی سرور کپی کنید (از طریق `git clone` یا آپلود فایل‌ها):

```bash
git clone <آدرس-ریپازیتوری-شما> parseh_project
cd parseh_project
```

۲. اسکریپت نصب خودکار را اجرا کنید:

```bash
sudo bash setup.sh
```

این اسکریپت به‌صورت خودکار موارد زیر را انجام می‌دهد:

- نصب PostgreSQL، Redis، Nginx و پایتون ۳.۱۲
- ساخت دیتابیس و کاربر PostgreSQL با رمز تصادفی امن
- کپی پروژه به مسیر `/opt/parseh_project`
- ساخت فایل `.env` با مقادیر پیش‌فرض (نیازمند تکمیل دستی برخی مقادیر مانند `DEEPSEEK_API_KEY`)
- ساخت محیط مجازی و نصب وابستگی‌ها
- اجرای `migrate` و `collectstatic`
- فعال‌سازی سرویس‌های systemd برای Gunicorn و Celery
- تنظیم و فعال‌سازی Nginx
- پیشنهاد فعال‌سازی SSL رایگان با Certbot

۳. کاربر مدیر (superuser) بسازید:

```bash
cd /opt/parseh_project
source venv/bin/activate
python manage.py createsuperuser
```

۴. فایل `.env` را ویرایش کرده و کلید DeepSeek را وارد کنید:

```bash
sudo nano /opt/parseh_project/.env
# DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxx
sudo systemctl restart parseh parseh-celery parseh-celery-beat
```

سایت شما اکنون در آدرس دامنه یا IP سرور در دسترس است. 🎉

## 🔑 متغیرهای محیطی (.env)

| متغیر | توضیح |
|---|---|
| `SECRET_KEY` | کلید امنیتی جنگو (با `openssl rand -hex 32` تولید کنید) |
| `DEBUG` | حالت دیباگ (`False` در تولید) |
| `ALLOWED_HOSTS` | دامنه‌ها/آی‌پی‌های مجاز، با ویرگول جدا شوند |
| `DB_NAME` / `DB_USER` / `DB_PASSWORD` | اطلاعات اتصال به PostgreSQL |
| `REDIS_URL` | آدرس اتصال Redis |
| `DEEPSEEK_API_KEY` | کلید API سرویس DeepSeek |
| `DEEPSEEK_MODEL` | مدل مورد استفاده (پیش‌فرض: `deepseek-chat`) |
| `ADMIN_URL` | مسیر پنل ادمین (پیش‌فرض `admin/`؛ حتماً قبل از استقرار واقعی تغییرش بده) |
| `SITE_NAME` / `SITE_PHONE` / `SITE_WHATSAPP` / `SITE_EMAIL` / `SITE_ADDRESS` | اطلاعات نمایشی سایت |
| `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` | برای اعلان تلگرام درخواست‌های تماس جدید (اختیاری - خالی بگذارید تا غیرفعال بماند) |

فایل نمونه در `.env.example` موجود است.

## 🔒 امنیت

پیش از استقرار روی سرور واقعی، این موارد از قبل برای شما رعایت شده:

- **مسیر ادمین قابل تغییر** — با `ADMIN_URL` در `.env` مسیر `/admin/` را به چیزی غیرقابل‌حدس تغییر بده.
- **محدودیت نرخ درخواست (Rate Limiting)** — فرم تماس (۱۰ درخواست/ساعت به ازای هر IP) و تحلیل هوشمند AI (۵ درخواست/ساعت به ازای هر IP، چون هر فراخوانی هزینه واقعی از API پولی DeepSeek کم می‌کند).
- **هانی‌پات ضداسپم** — یک فیلد نامرئی در فرم‌های تماس که فقط ربات‌ها پر می‌کنند.
- **اعتبارسنجی ورودی** — شماره تماس با regex، محدودیت طول پیام، محدودیت نوع و حجم فایل‌های آپلودی (حداکثر ۵ مگابایت، فقط jpg/jpeg/png/webp).
- **هدرهای امنیتی** — HSTS (وقتی SSL فعال باشد)، X-Frame-Options، Referrer-Policy، کوکی‌های HttpOnly/SameSite.
- **timeout روی فراخوانی DeepSeek** — جلوگیری از قفل‌شدن سرور در صورت کندی سرویس خارجی.
- **لاگ فایل چرخشی** — خطاها جدا در `logs/django-error.log` ذخیره می‌شوند (حداکثر ۵ فایل × ۵ مگابایت).

### چک‌لیست قبل از انتشار عمومی
- [ ] `ADMIN_URL` را به یک مسیر تصادفی تغییر بده
- [ ] `SECRET_KEY` را با `openssl rand -hex 32` تولید کن (نه مقدار پیش‌فرض)
- [ ] بعد از فعال‌سازی SSL، `SECURE_SSL_REDIRECT=True` را در `.env` قرار بده
- [ ] رمز عبور قوی برای دیتابیس PostgreSQL تنظیم کن
- [ ] `python manage.py createsuperuser` را با یک نام‌کاربری/رمز قوی (نه admin/admin) اجرا کن
- [ ] فایروال سرور را فعال کن (فقط پورت‌های ۲۲، ۸۰، ۴۴۳ باز باشند)

## ✨ قابلیت‌های پیشرفته (فاز ۳)

### جستجوی پیشرفته
در صفحه لیست املاک، علاوه بر نوع معامله و قیمت، می‌توان بر اساس متراژ، تعداد اتاق و امکانات (آسانسور، پارکینگ، انباری، بالکن) فیلتر کرد و نتایج را مرتب‌سازی کرد.

### نقشه تعاملی
با کلیک روی «نمایش/بستن نقشه» در صفحه لیست، یا به‌صورت خودکار در صفحه جزئیات ملک، نقشه‌ای مبتنی بر **Leaflet + OpenStreetMap** (رایگان، بدون نیاز به API Key) نمایش داده می‌شود. فقط ملک‌هایی که مختصات جغرافیایی (latitude/longitude) دارند روی نقشه دیده می‌شوند.

### علاقه‌مندی‌ها و مقایسه
کاربران بدون نیاز به ثبت‌نام می‌توانند با کلیک روی آیکون قلب، ملک را به علاقه‌مندی‌ها اضافه کنند، یا با آیکون مقایسه، تا ۳ ملک را برای مقایسه کنار هم انتخاب کنند (ذخیره‌سازی از طریق session مرورگر).

### پرسش‌های متداول
صفحه `/پرسش-های-متداول/` که از پنل ادمین (`FAQ`) مدیریت می‌شود؛ دیتای نمونه با دستور `seed_data` وارد می‌شود.

### سئو
- `sitemap.xml` به‌صورت خودکار از تمام ملک‌ها، مقالات و صفحات اصلی ساخته می‌شود.
- `robots.txt` مسیر ادمین و صفحات session-محور (مقایسه/علاقه‌مندی) را از ایندکس‌شدن مستثنی می‌کند.
- تگ‌های Open Graph برای نمایش بهتر لینک‌ها در واتساپ/تلگرام/توییتر روی صفحات ملک و مقاله فعال است.

### اعلان تلگرام
با تنظیم `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID` در `.env`، هر درخواست تماس جدید فوراً به تلگرام مدیر سایت ارسال می‌شود (از طریق Celery؛ در صورت غیرفعال بودن Celery، به‌صورت همزمان و بی‌خطر تلاش می‌شود).

راهنمای ساخت ربات تلگرام:
1. به [@BotFather](https://t.me/BotFather) پیام دهید و با `/newbot` یک ربات بسازید تا توکن بگیرید.
2. ربات را استارت کنید و chat_id خود را از [@userinfobot](https://t.me/userinfobot) بگیرید.
3. مقادیر را در `.env` قرار دهید.

## 👤 سیستم کاربری (فاز ۴)

- ثبت‌نام / ورود / خروج / تغییر رمز عبور، از مسیر `/حساب-کاربری/`
- **پروفایل و داشبورد کاربر**: علاقه‌مندی‌ها، بازدیدهای اخیر، درخواست‌های تماس ارسالی، ویرایش نام/ایمیل/تلفن
- **علاقه‌مندی‌های ماندگار**: برای کاربر واردشده، علاقه‌مندی‌ها در دیتابیس ذخیره می‌شود (نه فقط مرورگر) و از هر دستگاهی قابل مشاهده است
- **ادغام خودکار session**: اگر کاربری قبل از ثبت‌نام/ورود چند ملک را به علاقه‌مندی مرورگر (session) اضافه کرده باشد، بعد از ورود به‌صورت خودکار به حسابش منتقل می‌شود
- **تاریخچه بازدید**: هر بار که کاربر واردشده صفحه یک ملک را باز کند، در پروفایلش ثبت می‌شود
- فرم تماس برای کاربر واردشده با نام/ایمیل/تلفن پروفایلش از قبل پر می‌شود و درخواست به حسابش متصل می‌شود
- لیست مقایسه (Compare) همچنان session-محور است و نیازی به ورود ندارد (ابزار کوتاه‌مدت)

> نکته: مدل‌های جدید (`Profile`, `Favorite`, `PropertyView`, و فیلد `user` روی `ContactRequest`) نیاز به `makemigrations` و `migrate` دارند.

## 🧑‍💼 پنل مشاوران و گزارش‌گیری مدیر (فاز ۵)

### پنل اختصاصی مشاوران — `/پنل-مشاور/`
- برای فعال‌سازی، از پنل ادمین (`TeamMember`) فیلد «حساب کاربری مرتبط» را برای هر مشاور به یک User متصل کنید.
- مشاور فقط ملک‌های خودش را می‌بیند، می‌تواند ملک جدید اضافه کند، ویرایش کند یا از انتشار خارج کند (حذف نرم؛ سابقه بازدید/علاقه‌مندی حفظ می‌شود).
- درخواست‌های تماس مربوط به ملک‌های خودش را می‌بیند و می‌تواند «خوانده‌شده» علامت بزند.
- کاربران `is_staff` (مدیر) به پنل همه‌ی مشاوران دسترسی کامل دارند (برای پشتیبانی).

### گزارش‌گیری مدیر — `/گزارش-مدیریت/`
فقط برای `is_staff` قابل مشاهده است. شامل:
- آمار کلی: تعداد ملک، بازدید، کاربران، درخواست تماس، علاقه‌مندی، مقالات وبلاگ
- پربازدیدترین ملک‌ها (نمودار میله‌ای)
- روند هفتگی درخواست‌های تماس و عضویت کاربران (۸ هفته اخیر)
- جدول عملکرد هر مشاور (تعداد ملک، مجموع بازدید، درخواست‌های نخوانده)

> نکته: مدل‌های جدید (فیلد `user` روی `TeamMember`) نیاز به `makemigrations` و `migrate` دارند.

## 🔑 فراموشی رمز عبور و ارزیابی آنلاین ملک (فاز ۶)

### فراموشی رمز عبور
- مسیر: `/حساب-کاربری/رمز-فراموش-شده/` (لینکش در صفحه ورود هم هست)
- در محیط توسعه، ایمیل به‌جای ارسال واقعی در **کنسول ترمینال** چاپ می‌شود (`EMAIL_BACKEND` کنسولی) — لینک بازنشانی را از آنجا کپی کنید.
- در تولید، حتماً `EMAIL_HOST` / `EMAIL_HOST_USER` / `EMAIL_HOST_PASSWORD` را در `.env` تنظیم کنید تا ایمیل واقعی ارسال شود.

### درخواست آنلاین ارزیابی ملک
- صفحه عمومی: `/املاک/ارزیابی-ملک/` (لینکش در صفحه اصلی، فوتر و منو موجود است)
- مالک ملک می‌تواند بدون نیاز به ثبت‌نام، مشخصات و حداکثر ۳ تصویر ملک خود را ثبت کند.
- دارای rate limit (۵ درخواست در ساعت) و هانی‌پات ضداسپم، مشابه فرم تماس.
- با ثبت هر درخواست، اعلان تلگرام به مدیر ارسال می‌شود (در صورت تنظیم `TELEGRAM_BOT_TOKEN`).
- مشاوران از پنل خودشان (`/پنل-مشاور/ارزیابی-ملک/`) درخواست‌های «در انتظار بررسی» را می‌بینند و می‌توانند با دکمه «پیگیری با من» آن را برای خود claim کنند و وضعیتش را به‌روزرسانی کنند.

## ⚡ بهبود عملکرد

- **کش Redis** برای کوئری‌های صفحه اصلی (۱۵ دقیقه، با ابطال خودکار هنگام ثبت/ویرایش ملک یا مشاور)
- **فشرده‌سازی خودکار عکس** هنگام آپلود (حداکثر ۱۶۰۰ پیکسل، کیفیت ۸۲٪) — فقط روی فایل‌های تازه‌آپلودشده اجرا می‌شود، نه فایل‌های قبلی
- **رفع N+1 Query** با `select_related` در چند صفحه (جزئیات ملک، پروفایل کاربر، پنل مشاور، مدیریت مشاوران)
- **ایندکس دیتابیس** روی فیلدهای پرکاربرد ملک (`is_published`, `transaction_type`, `price`, `views_count`, `created_at`)
- **Lazy loading** روی تمام تصاویر به‌جز تصویر اصلی گالری صفحه ملک

> نکته: چون ایندکس جدید به مدل `Property` اضافه شده، این‌بار هم `makemigrations` و `migrate` لازم است.

## 🛠️ دستورات مدیریتی رایج

```bash
# فعال‌سازی محیط مجازی
source /opt/parseh_project/venv/bin/activate

# اجرای مایگریشن‌ها پس از تغییر مدل‌ها
python manage.py makemigrations
python manage.py migrate

# جمع‌آوری فایل‌های استاتیک
python manage.py collectstatic --noinput

# مشاهده وضعیت سرویس‌ها
sudo systemctl status parseh
sudo systemctl status parseh-celery
sudo systemctl status parseh-celery-beat

# مشاهده لاگ‌ها
sudo journalctl -u parseh -f
tail -f /opt/parseh_project/logs/gunicorn-error.log

# ری‌استارت سرویس‌ها بعد از تغییرات
sudo systemctl restart parseh parseh-celery parseh-celery-beat
sudo systemctl reload nginx
```

## 🧪 تست‌های خودکار

پروژه شامل ۳۹ تست خودکار (`apps/*/tests.py`) روی مهم‌ترین و پرریسک‌ترین بخش‌هاست:

| فایل | چیزهایی که تست می‌کند |
|---|---|
| `apps/properties/tests.py` | اسلاگ خودکار، فیلترها، لایک (session و حساب کاربری)، محدودیت ۳تایی مقایسه، **رگرسیون باگ CSRF** |
| `apps/contact/tests.py` | اعتبارسنجی شماره تلفن، هانی‌پات ضداسپم، اتصال درخواست به حساب کاربری |
| `apps/accounts/tests.py` | ساخت خودکار پروفایل، ثبت‌نام، **ادغام علاقه‌مندی مهمان به حساب هنگام ورود** |
| `apps/advisor_panel/tests.py` | **مهم‌ترین فایل امنیتی**: مشاور نتواند ملک مشاور دیگر را ببیند/ویرایش/حذف کند |
| `apps/team/tests.py` | نمایش فقط ملک‌های منتشرشده در صفحه مشاور |

اجرا:
```bash
python manage.py test
```

اجرای فقط یک اپ خاص:
```bash
python manage.py test apps.advisor_panel
```

اجرا با جزئیات بیشتر:
```bash
python manage.py test --verbosity=2
```

> نکته: تست‌ها از دیتابیس تستی جداگانه استفاده می‌کنند (خودکار ساخته و در پایان پاک می‌شود)، پس هیچ آسیبی به دیتای واقعی سایت نمی‌زنند.

## 🔄 استقرار خودکار با CI/CD (GitHub Actions)

فایل `.github/workflows/deploy.yml` با هر `push` به شاخه‌ی `main`:

1. تست‌های پروژه را روی یک دیتابیس PostgreSQL موقت اجرا می‌کند.
2. در صورت موفقیت تست‌ها، از طریق SSH به سرور شما متصل شده و به‌صورت خودکار:
   - آخرین کد را `pull` می‌کند
   - وابستگی‌ها را به‌روزرسانی می‌کند
   - `migrate` و `collectstatic` را اجرا می‌کند
   - سرویس‌های Gunicorn و Celery را ری‌استارت می‌کند

### تنظیم Secrets مورد نیاز در ریپازیتوری گیت‌هاب:

| Secret | توضیح |
|---|---|
| `SSH_PRIVATE_KEY` | کلید خصوصی SSH برای اتصال به سرور |
| `VPS_HOST` | آدرس IP یا دامنه سرور |
| `VPS_USER` | نام کاربری SSH (مثلاً `root` یا `deploy`) |

> نکته: کاربر سرویس‌دهنده باید بدون رمز عبور اجازه‌ی اجرای `sudo systemctl restart` را داشته باشد (با تنظیم `visudo`).
